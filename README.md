# kakeibo-system

マネーフォワード ME の家計データを GitHub に貯めて、Cloudflare で見せる「家計の仕組み」のテンプレートです。
マネーフォワードの弱点である「予算管理」と「引落口座ごとの資金繰り」を、自分のデータで補うために作っています。

> 注意：このリポジトリに実データは入れないでください。同梱のデータはすべて架空のサンプルです。

## クイックスタート

1. 右上の「Use this template」から、自分のリポジトリとしてコピーする
2. `data/sample/` のサンプルデータのまま、`site/` の表示ページを Cloudflare Pages にデプロイして見た目を確認する
3. サンプルデータを自分の家計データ（マネーフォワードから書き出した月次データ）に差し替える

## 構成

- `data/`：月次データ（JSON）の置き場。`sample/` に架空のサンプルが入っています
- `site/`：Cloudflare Pages で表示するページ（準備中）
- `src/`：集計などの処理コード（必要になったら追加）
